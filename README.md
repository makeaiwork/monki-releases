# Monki releases

Public update channel for Monki, a macOS menu bar app for external monitor brightness and volume.

- Signed, notarized application downloads will be attached to GitHub Releases.
- `appcast.xml` is the signed Sparkle update feed. It is initially empty until the first release is published.
- Application source code is maintained separately.

Existing installations without Sparkle need a one-time manual installation of the first Sparkle-enabled release.
